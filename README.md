# CORDÓN · Café de especialidad

> Tienda online con catálogo, filtros y carrito para comercios y emprendedores. Catálogo navegable, carrito en tiempo real y checkout — pensada mobile-first.

**🔗 Demo en vivo:** https://tienda-cordon.vercel.app
**🛠️ Hecho con:** Next.js · TypeScript · Tailwind CSS

---

## El problema

Muchos comercios chicos venden por DM de Instagram o catálogo de WhatsApp: sin carrito, sin orden, con precios sueltos y pedidos que se arman a mano. Se pierden ventas y tiempo.

## La solución

Una tienda navegable con carrito real:

- Catálogo en grilla con filtros por categoría para que el cliente encuentre rápido.
- Carrito en tiempo real: agregar, sumar/restar cantidad, eliminar y ver el total al instante.
- Checkout claro que confirma el pedido.

## Características

- **Catálogo con filtros** — el cliente acota por categoría / perfil.
- **Carrito en vivo** — drawer lateral con cantidades, eliminación y total actualizado al instante.
- **Checkout** — confirmación de pedido.
- **Totalmente responsive** — mobile-first, porque la mayoría compra desde el celular.
